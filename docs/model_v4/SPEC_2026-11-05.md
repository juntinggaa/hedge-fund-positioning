# Model v4: adapting to changing relationships

Specification written on 2026-11-05 before fitting any v4 candidate. Existing v2/v3 results motivated this experiment, so it is exploratory, not a fresh confirmatory test. No post-cutoff CFTC data are used.

## Question and scope

Does changing the estimation history, or calibrating with earlier out-of-sample predictions, improve the existing 40-feature M3? The target remains the same-week change in leveraged-fund net / open interest. This remains a retrospective conditional estimate, not a pre-release or next-week forecast. No new features, raw-data refresh, LLM runs, stimulus changes, or production-model replacement.

## Fixed candidates

All use ridge, the existing 13-alpha grid `logspace(-2, 4, 13)`, four inner chronological CV splits, initial outer training of 260 observations, and refitting every 13 observations.

| Name | Training history |
|---|---|
| expanding | All earlier eligible observations, equal weight (M3 reference) |
| rolling_156 | Most recent 156 eligible observations |
| rolling_260 | Most recent 260 eligible observations |
| rolling_520 | Most recent 520 eligible observations, or all earlier observations until 520 exist |
| weighted_104 | All earlier observations, exponential weights with 104-calendar-week half-life |
| weighted_260 | All earlier observations, exponential weights with 260-calendar-week half-life |

Weights are `2 ** (-age_in_calendar_weeks / half_life)`, relative to the latest date in each fit, normalised to mean one within that fit. Both StandardScaler and Ridge receive these weights. Every inner CV fit recomputes weights using only that inner training fold. Inner validation loss is unweighted MSE, since the goal is performance on the next block of weeks. Equal-weight expanding and rolling_260 must reproduce the existing v2 predictions within numerical tolerance; otherwise investigate before evaluating new results.

## Calibration (six additional variants)

For each raw scheme, fit `actual = intercept + slope * raw_prediction` by OLS on its most recent 104 **earlier outer out-of-sample** prediction/actual pairs. Require 52 such pairs. Fit at each outer refit date, using dates strictly earlier than the first test week, then hold the calibrator fixed throughout the 13-week test block. Training fitted values and predictions for the current test block never enter calibration. No full-sample rescaling, fitted-value calibration, clipping, or parameter search. Degenerate predictor variance falls back to slope 1 and the past mean error as intercept; record every fallback.

## Samples and benchmarks

M3 feature-complete data contain 980 observations (2007-09-11 to 2026-09-08). The raw outer predictions cover 720 weeks, 2012-11-27 to 2026-09-08. Primary comparison is the common **668 weeks, 2013-11-26 to 2026-09-08**, after 52 earlier OOS predictions exist. Report raw-only 720-week results separately as context. All candidates use identical evaluation weeks and one common historical-mean benchmark (existing v2 B1); also report zero-change benchmark. Rolling and weighted models do not get their own easier benchmark.

## Metrics, inference, and selection

- OOS R² versus common historical mean and zero change; RMSE, MAE, bias, prediction SD, Mincer-Zarnowitz slope/intercept, residual autocorrelation.
- Paired squared-error differences versus expanding raw, Newey-West HAC with 4 lags, one-sided improvement p-values, stationary bootstrap 90% intervals (mean block 13, 2,000 draws, seed 20261105). Use common bootstrap draws for all candidates.
- Holm-adjust the 11 candidate-versus-reference p-values as one family. A replacement recommendation requires adjusted p < 0.10 **and** bootstrap lower bound for MSE improvement > 0. Otherwise retain M3. This is more conservative than the earlier unadjusted gates and does not revise their outcomes.
- Calibration versus its own raw scheme is secondary, with a separate six-test Holm family; do not use those tests to bypass the replacement rule.
- Fixed era reporting: 2013-16, 2017-19, 2020-22, 2023-26. Show post-2021 subset only as descriptive context, not another selection opportunity.
- Report effective sample size and chosen alphas per refit, calibration slopes, residual-ranking overlap, and raw-change overlap. No post-result tuning.
