# Model v3 factor experiment: specification

**Frozen 2026-11-05, before any v3 feature was built or fitted.** Data-availability
checks done before freezing (no target data involved): FiscalData auction fields
and date coverage (1979-10-31 onward); NY Fed primary-dealer (PD) series list,
series-break table, history start (as-of 2013-04-03), and the placement of `*`
placeholders. Nothing here was chosen by looking at v3 fit results. Changes after
fitting go in an *Amendments* section with a date and a reason.

v1 and v2 results, predictions, stimuli, pilot responses and pinned data are
**not modified** (see §9). v3 writes only to `docs/model_v3/`, `reports/model_v3/`,
`data/processed/model_v3/`, `data/raw/v3/`, and `data/manifests/v3_*`.

**Contamination.** All v1/v2 out-of-sample results were seen before this spec.
v3 is exploratory. A null result is an acceptable outcome.

## 1. Question and target

Unchanged from v2 (`docs/model_v2/SPEC_2026-11-05.md` §1–2, with Amendment 1):
- Primary target `y_t = s_t − s_{t−1}`, `s` = leveraged-fund net / OI, UST 10Y
  (`043602`), futures-only TFF. Units: percentage points of OI (pp).
- Robustness target `(N_t − N_{t−1}) / OI_{t−1}`, compared only by R² against
  its own benchmarks and by prediction correlation.
- Description: **retrospective same-week conditional estimate**. It is not a
  pre-release nowcast, because `d_log_oi` uses week *t*'s CFTC open interest.

## 2. Reference model

**M3** = v2.0's selected model: the v1 extended feature list, ridge (Pipeline:
StandardScaler, Ridge; α from `RIDGE_ALPHAS` = logspace(−2, 4, 13) by GridSearchCV
with TimeSeriesSplit(4)), expanding window, minimum 260 training weeks, refit
every 13 weeks. Every v3 candidate uses **the same estimator, grid, CV and walk**.
Only the feature list changes.

## 3. Candidate blocks

### Block S: Treasury coupon supply (FiscalData `auctions_query`)

Hypothesis (non-causal): coupon supply in or near the 10-year sector changes the
cash–futures balance that leveraged funds hold futures against, so supply
settling this week, or already auctioned and about to settle, may be associated
with the week's change in leveraged-fund net position.

Universe: `security_type` ∈ {Note, Bond}, excluding `inflation_index_security =
Yes` (TIPS) and `floating_rate = Yes` (FRNs). Bills excluded. Reopenings included.
**10y sector** = `original_security_term` ∈ {7-Year, 10-Year}.

Amount: `total_accepted` (auction result, known on `auction_date`). Never used
before `auction_date`. `offering_amt` (known on `announcemt_date`) is used only
for announced-but-not-yet-auctioned issues.

Snapshot interval for week *t* = (previous CFTC snapshot, snapshot *t*], using
the actual snapshot dates (holiday weeks included). All dates are calendar
dates. An event dated on snapshot day *t* counts as known at *t*: CFTC positions
are as of Tuesday close, and auction results are released at about 1 pm ET.

| feature | definition | timing |
|---|---|---|
| `s_settle_10s` | Σ `total_accepted` of 10y-sector issues with `issue_date` in the interval | settlement dates ≤ *t* |
| `s_pending_10s` | Σ `total_accepted` of 10y-sector issues with `auction_date` ≤ *t* < `issue_date` | auctioned, not settled |
| `s_announced_10s` | Σ `offering_amt` of 10y-sector issues with `announcemt_date` ≤ *t* < `auction_date` | announced, not auctioned; no auction result used |
| `s_settle_dur_all` | Σ over all coupon issues settling in the interval of `total_accepted` × w(term), where w = APPROXIMATE 10y-equivalent duration weight {2Y .22, 3Y .32, 5Y .53, 7Y .72, 10Y 1, 20Y 1.6, 30Y 2.1} by `original_security_term` (fixed, labelled approximation) | settlement dates ≤ *t* |

Scaling (prior-only): each raw $ sum is divided by its own trailing mean over
the previous 52 snapshots, *t* excluded, then log1p-transformed. The trailing
mean uses auction history from 1979, so there are no gaps in the CFTC sample.

**Net issuance is not built.** Maturing amounts would have to be reconstructed
from issue records net of buybacks and partial reopenings, and that
reconstruction is not reliable enough here. Gross supply only; disclosed.

### Block D: primary-dealer inventory (NY Fed PD API), lagged

Hypothesis (non-causal): dealer net Treasury inventory is the other side of
client positioning, and a lagged inventory build may be associated with this
week's leveraged-fund adjustment.

Series (keyids from the current SBN2024 list; the API returns them from as-of
2013-04-03):
- `PDPOSGSC-G7L11`: net outright position, coupons due in more than 7 and up to
  11 years, $ mn.
- `PDPOSGST-TOT`: net outright position, Treasury securities excluding TIPS,
  total, $ mn.

**Release timing.** The PD weekly report is as of Wednesday and released the
following Thursday, about 8 days later. The API has no release timestamps, so a
conservative rule is used: a value as of date *a* is available at snapshot *t* only
if `a + 9 days ≤ t` (one day of buffer for holiday delays). For a Tuesday
snapshot this selects the Wednesday 13 days earlier. No value is used before its
assumed release date.

| feature | definition |
|---|---|
| `d_coup711_z` | latest available G7L11 value, z-scored against the previous 156 available values (prior-only, *t* excluded) |
| `d_coup711_ch4_z` | 4-release change in G7L11, divided by the SD of 4-release changes over the previous 156 |
| `d_ust_tot_z` | same as `d_coup711_z` for PDPOSGST-TOT |
| `d_ust_tot_ch4_z` | same as `d_coup711_ch4_z` for PDPOSGST-TOT |

**Secondary (reported, not eligible for selection):** fails,
`log(PDFTD-USTET + PDFTR-USTET)`, z-scored the same way (`d_fails_z`).

**Financing excluded from the primary block.** Repo (`PDSORA-UTSETTOT`) and
reverse repo (`PDSIRRA-UTSETTOT`) totals carry `*` placeholders in 14–30% of
weeks from 2022 on (runs up to 12 weeks), which coincides with the SBN2022
redefinition. They are not harmonisable without imputation, and imputation is
not done. Disclosed as untested.

**Series-break audit (pre-specified).** For each D series, at each break start
(2015-01-01, 2022-01-05, 2024-07-03), report the first post-break weekly change
as a percentile of absolute weekly changes in the preceding 156 weeks. A change
above the 99th percentile is flagged. **A flagged break is disclosed, not
corrected.** The D comparison is then repeated with each flagged break absorbed:
z-scores reset, with a 156-week burn-in restarted after the break. That is a
sensitivity check, not the primary result.

**Missing data.** No zeros, no future values, no interpolation. D features exist
from about 2013-04-16 on. Weeks before then are not in the D sample.

## 4. Comparisons and samples

| comparison | sample | reference |
|---|---|---|
| M3 vs M3+S | full M3 sample | M3 v2.0 refitted (identical) |
| M3 vs M3+D | weeks where D features exist ("D sample") | **M3 refitted on the D sample**, same start week, same walk |
| M3 vs M3+S+D | D sample | M3 on the D sample |
| M3+D+fails (secondary) | D sample | M3 on the D sample |

The comparisons use identical out-of-sample weeks within each row. As context,
v2.0 M3's own predictions restricted to the D sample's out-of-sample weeks are
also reported. Weeks are not mixed across rows.

## 5. Reporting (all candidates)

- OOS R² vs B1 (expanding mean) and vs B0 (zero change = random walk in level);
  AR(1) benchmark B2 on the same weeks.
- RMSE and MAE in pp of OI.
- Paired loss differential vs the matched M3: mean ΔMSE, Newey–West HAC (4 lags)
  one-sided p, and a 90% stationary bootstrap CI (mean block 13, 1000 reps, seed
  20260918). The CI is the time-series interval on the improvement.
- Era stability: ΔMSE by era (full sample: 2011–12, 2013–16, 2017–19, 2020–22,
  2023–26; D sample: by available eras).
- Residual-ranking change: overlap of the top 10% |residual| weeks vs matched M3.
- Robustness target: R² vs its own benchmarks, both for M3 and the candidate on
  the same weeks.
- Fitted coefficient signs are described as associations, never as causes.

## 6. Selection rule (same gate as v2)

A candidate replaces M3 only if, against its matched M3: HAC one-sided p < 0.10
**and** the 90% bootstrap CI of the mean MSE reduction lies above 0. Otherwise
M3 is retained. If a D-sample candidate passes, it still cannot replace M3 for
weeks before its out-of-sample start (about 2018). Adopting it would change the
stimulus weeks, so it goes to the team as a decision, not an automatic switch.
The v2 gate outcome (M4: p = 0.095, CI includes 0, not adopted) stays disclosed
and is not revisited.

## 7. Genuine basis data (investigation only, not fitted)

Check whether a public, downloadable series of implied repo minus financing
rate, or a CTD net basis, exists with documented conventions. Record what is
missing (CTD prices, conversion factors, term repo, delivery option value). Do
not reconstruct a basis from event-window figures in papers.

## Amendments

**Amendment 1 (2026-11-05, after fetching, before any fit).** Two implementation
details the text above left open:
- Non-standard original terms (e.g. `5-Year 2-Month`, `4-Year`) get duration
  weights by linear interpolation in years between the listed tenors. The 10y
  sector stays exactly {7-Year, 10-Year}.
- The pre-specified break audit flagged **no** break above the 99th percentile
  (`reports/model_v3/pd_break_audit.csv`). So the reset-after-break sensitivity
  run is not triggered. The audit only tests for level jumps; it cannot detect a
  definitional change that leaves the level smooth. That limitation is disclosed.
